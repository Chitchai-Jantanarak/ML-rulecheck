# Frontend

This is a Next.js application for the ML Rule Check frontend.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:4000](http://localhost:4000) with your browser to see the result.

## Backend API

This application expects the backend API to be running on `http://localhost:8000` by default. You can configure this by setting the `NEXT_PUBLIC_BACKEND_URL` environment variable.
